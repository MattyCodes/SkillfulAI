# AI Skills & Resources
This repository should serve as a (reasonably) generic collection of instructions, guidelines, and skills of varying specificity the coding agents can use.

## Intended Use
The hope is that other repositories can contain AI instructions that simply point the agent to this public repository for whatever skills and best practices they need to be aware of.

The core if this collection will be `the-prime-directive.md`, which contains very generalized guidelines about writing code carefully and cleanly; my intention is for that document to be a part of the context of every agent and prompt.

The `skills` directory, and the directories inside of it, should contain more narrowly defined skills/practices (organized by language, framework, and so forth).

Some of the instructions will be a matter of personal preference (particularly around organization, style/lint rules etc); if you find some of these skills and artifacts useful, but disagree with others, feel free to fork this project and adjust the instructions to your liking.
